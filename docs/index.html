Towel is a small credential broker for projects operated by coding agents. The child gets a fake key and a loopback URL. The real key stays in an encrypted vault opened only by Towel and reaches only the exact routes authorized for this session.

02 / Security boundary

Useful protection, precise claims

✓ Towel protects

  • The real project key from the child environment
  • Encrypted destinations and policies from workspace edits
  • Multiple credentials isolated between session routes
  • Authentication from hostile client headers
  • Accidental plaintext and base64 key reflection

× Towel is not

  • A sandbox or enterprise identity platform
  • Protection for the agent's own model login
  • A guard against actions performed through the broker
  • A boundary against host root, shared PID, or CAP_SYS_PTRACE

A small literary nod

Why a towel?

Douglas Adams made the towel an icon of lightweight, improbable usefulness. This one is similarly unassuming: keep it beside your agent, put the dangerous credential behind it, and don't panic.

Open by design

Help make the boundary sharper.
